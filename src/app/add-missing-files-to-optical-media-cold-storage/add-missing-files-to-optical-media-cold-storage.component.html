Add new files to my cold storage

Your files are in a folder, and you have the metadata JSON of this cold storage. The app finds the files that are new since your last backup and burns only those onto new discs.
album

Build the metadata JSON from my discs

You have the discs but not the metadata JSON. The app asks where to save a new one, then reads your existing discs one at a time and records what is on each of them. Nothing is burned, and no folder of your original files is needed.
playlist_add

Update cold storage metadata with existing (already burnt) discs

You have the metadata JSON, but it does not cover every disc you have burned. The app asks for that JSON, then reads the discs it is missing, in order, and adds them to it. Nothing is burned, and no folder of your original files is needed.
