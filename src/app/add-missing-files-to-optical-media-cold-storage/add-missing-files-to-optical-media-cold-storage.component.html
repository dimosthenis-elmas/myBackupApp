Note for this checkbox: For this application to determine the new files, i.e. files missing from your cold storage but present in your 'master' (as in a cumulative backup fashion) we need to read all the metadata (path, file size etc.) for all the files in each one of the optical discs. When this checkbox is unchecked, you are asked to place all your optical discs (spaning the entire cold storage) one by one in the optical disc reader device in order to accumulate all the required metadata so that we can then determine what is missing from your cold storage. Since this is quite a tedious process, you can provide a JSON file containing said metadata. Now, how do I create this file you may ask. You simply run this process once by unsetting this checkbox and then the application will save this JSON file for you. You may then use this file for a future update of your cold storage. You have to be careful to make sure that the provided JSON file is up to date.
